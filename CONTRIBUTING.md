# Contributing to SpeechDesk

Thanks for helping! Bug reports and ideas are welcome in [Issues](https://github.com/fmrgcarvalho/speechdesk/issues).

## Pull requests

- Keep changes focused; run `dotnet test tests/SpeechDesk.Core.Tests` before opening the PR.
- Match the style of the surrounding code (comments in the code are in Portuguese, user-facing text goes
  through `L.T(...)` in both English and Portuguese).
