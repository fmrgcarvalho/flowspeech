Made for people who write all day

It works in every Windows app, because SpeechDesk types wherever the cursor is — no integrations needed.

English and Portuguese

The speech model covers 25 European languages, including English and European Portuguese, and detects on its own when you switch mid-sentence.

Spoken punctuation

Say “comma”, “full stop” or “new line” and you get the punctuation. The “um”s and “uh”s disappear.

Dictionary and snippets

Teach it names and technical terms. Say “my email” and the full address appears.

AI clean-up optional

When you correct yourself (“at 3, no, at 4”), only the final version stays. Fixes grammar and adapts the tone to the app.

Speak Portuguese, type English optional

Turn on translation in the menu and the text comes out in English, about one to two seconds after you let go of the key.

Private by default

Transcription, clean-up and translation run on your processor. History stays in a local file.

Shortcuts

A single key, and you can change it. AI clean-up and translation are switched on from the icon menu next to the clock.

ShortcutWhat it does
Hold Right CtrlRecords while the key is held; types the text when you let go.
Double-tap Right CtrlHands-free mode: records without holding the key.
Tap Right CtrlIn hands-free mode, stops and types the text.
EscCancels the recording.
Right Ctrl + another keyCancels — it is a normal shortcut, like Ctrl+C.

Models that run on your PC

Pick the engine in the settings. Models are downloaded once with a script.

Speech to text — default

NVIDIA Parakeet TDT 0.6B v3

  • 25 European languages, including English
  • Very fast on CPU
  • ~0.7 GB · CC-BY-4.0 licence

Speech to text — alternative

OpenAI Whisper large-v3-turbo

  • 99+ languages
  • Built-in translation to English
  • ~0.55 GB · MIT licence

Clean-up and translation — optional

Qwen 2.5 1.5B Instruct

  • Runs inside the app, no server
  • Turn it on or off from the menu
  • ~1 GB · Apache 2.0 licence

Install

You need Windows 10 or 11 (x64), the .NET 8 SDK and 8 GB of RAM. Without AI, SpeechDesk uses about 1 GB; with AI, about 2.5 GB.

  1. Get the code

    git clone https://github.com/fmrgcarvalho/speechdesk.git
cd speechdesk

  2. Download the speech model

    Only once. Run it again with -Engine ai if you want AI clean-up, or translation with Parakeet.

    ./scripts/download-model.ps1

  3. Start it

    An icon appears next to the clock. Open Notepad, hold Right Ctrl and speak.

    dotnet run --project src/SpeechDesk.App
